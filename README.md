## 年付十几美元的小鸡：便宜之后看什么

这个价位能买到什么，取决于三个参数：内存、IPv4 形态、端口速率。任何一项缩水，省下的钱都不够补麻烦。

内存是第一条分界线。512MB 的年付套餐（比如 bytevirt $12/年，香港或美西可选）跑静态页、挂轻量代理还行，装个面板或数据库就紧张；1GB 起步的从容得多，cloudserver $10/年、dedione $12.99/年（洛杉矶，NVMe 盘，还带 2 个 IPv6）都在这一档。

IPv4 形态容易被忽略。台湾的 wap.ac 年付 $12 给的是 IPv6 加 20 个端口的 NAT IPv4，SSH 得连商家指定的外部端口；justhost 甚至有 $19.20 一年、一个 IPv4 都不给的档位。想省事，认准独立 IPv4，表 1 前三行都是。

端口速率决定流量的含金量。justhost 有 10Mbit 端口的 $13.92 档，满速下载也就 1.25MB/s；ColoCrossing 的 $11.99/年给 20TB 流量，但走普通美国线路。流量数字大，不等于体验好。

## 线路和延迟：同样的配置，价格为什么差十倍

差价买的是回国路由。1 核 1G 的配置，美西普通线路 $10/年，CN2 GIA-E 要 $169.99/年，香港 CN2 GIA 直接 $89.99/月，配置几乎一样，区别全在网络路径上。

延迟有物理下限，经验值大致是：香港 50ms 左右，日本 80ms 上下，美西 170ms 左右，美东 200ms 往上。换商家改变不了距离，能改变的是路由绕不绕、晚高峰丢不丢包。

搬瓦工的套餐分层很适合用来说明这个差价：$49.99/年的 CN2 套餐可在含 DC3 CN2 GT 的 8 个机房里选，入门够用；$169.99/年的 CN2 GIA-E 可选 DC6、DC9、日本软银、圣何塞、加拿大、荷兰等机房，2.5Gbps 端口，走优化直连；再往上，香港 CN2 GIA 就是 $89.99/月。这个差价值不值，测过才知道。

测的办法不难。买之前先找机房测试 IP：搬瓦工每个机房都公布测试 IP，比如 DC9 的是 89.208.246.192，Windows 按 Win+R 输 cmd 回车，敲 ping 加这个 IP；Mac 在终端里敲一样的命令。想看全国表现，用站长之家的 Ping 检测（ping.chinaz.com），结果按电信、联通、移动分列。已购用户直接在面板里拿 IP 测，搬瓦工的 SSH 连接信息就放在 KiwiVM 面板里。工具方面，ping.pe、ping.sx 输入 IP 就能看到全球各节点的数据，itdog.cn 记得切持续测试模式，boce.com 只提供延迟和简单丢包。

判断的时候记两条：丢包率比绝对延迟更重要，200ms 但零丢包的机器，用起来可能好过 100ms 却丢包 10% 的；建站和普通远程办公 200ms 以内都够用，打游戏、做实时交互才必须盯港日机房。别只测一次，晚高峰和凌晨的表现可能差很远。

## 真实总成本：续费价和计费周期要一起算

第二年的账单取决于续费价和计费周期，光看首年标价容易踩坑。

IONOS 是典型例子：XL 款首期 $14/月，一年 $168，但原价 $30/月，续费就是 $360/年，比第一年多出一倍多。Contabo 没有首年折扣这回事，$8.95/月一年约 $107，第二年不变。哪家真便宜，要看你打算用几年。

## 常见问题

### VPS 延迟多少算正常？

香港 50ms 左右、日本 80ms 上下、美西 170ms 左右、美东 200ms 往上，这是物理距离决定的下限。建站和普通远程办公 200ms 以内都可接受，游戏和实时应用尽量选港日机房。

### 512MB 内存的套餐还值得买吗？

静态页、轻量代理、学习用途可以，跑面板、数据库、Docker 会很勉强。预算加几美元上 1GB 更稳。

### 20TB 流量和 1TB 差别大吗？

个人使用 1TB/月很难用完，大流量档买的是踏实和突发余量。比流量更该看端口，10Mbit 端口的套餐流量再大也快不起来。

### 月付还是年付划算？

成熟商家年付更省，搬瓦工 GIA-E 年付比按季付省约 15%；不熟的商家先月付。有首年折扣的（比如 IONOS $14/月）要按原价 $30/月预估第二年的开销。

### 怎么判断一家小商家靠不靠谱？

看在售页面更新是否活跃、退款条款是否明确、有没有公开测试 IP。三样都查不到的，别年付。
